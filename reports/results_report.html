Cross-Lingual Prompt-Tuned XLM-R for Low-Resource NER in Telugu

This report compiles empirical evaluation results for parameter-efficient cross-lingual soft prompt tuning on XLM-RoBERTa for Telugu Named Entity Recognition (Naamapadam dataset). Soft prompt tuning updates only 0.0075% of parameters while achieving 0.4380 F1 at 100 target shots.
