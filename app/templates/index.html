Project Summary & Key Findings

Extremely low-resource languages like Telugu suffer from severe data scarcity in Named Entity Recognition (NER). Standard full fine-tuning requires updating all 277M parameters of XLM-R, which is computationally expensive and prone to overfitting on small target subsets. In this project, we implement Low-Rank Adaptation (LoRA r=8) with target module expansion ["query", "key", "value", "dense"], 10% linear warmup, and multilingual source transfer.

  • Parameter Efficiency: Updates only 1,332,487 parameters (0.4780%) vs 278M in full fine-tuning.
  • Near-Parity Performance: Reaches 0.7668 F1 (Peak Seed 2024: 0.7734 F1), recovering 98.36% of full fine-tuning F1.
  • Multilingual Source Advantage: Pre-tuning on combined English, Hindi, Tamil, and Malayalam data yields strong cross-lingual transfer supervision to low-resource Telugu.
