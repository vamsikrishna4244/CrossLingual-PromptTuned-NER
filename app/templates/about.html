Methodology & System Architecture

Comprehensive breakdown of parameter-efficient cross-lingual soft prompt tuning (LoRA-r8) for low-resource Named Entity Recognition in Telugu (te) and Kokborok (trp).

1. Introduction & Task Formulation (Section 1)

Named Entity Recognition (NER) is a core Natural Language Processing task that identifies and classifies named entity spans—specifically Person (PER), Location (LOC), and Organization (ORG)—within unstructured text. For high-resource languages like English, deep transformer models achieve $>90\%$ F1 scores. However, low-resource languages like Telugu (te) and un-pretrained indigenous languages like Kokborok (trp) suffer from severe training data scarcity and complex agglutinative morphology (e.g. locative case suffixes attached directly to city names such as Agartala-o).

2. Dataset & Languages (Section 2)

Experiments and evaluations are conducted across two target languages with explicit Train, Validation, and Testing sentence counts:

  • Target Language 1 (Telugu): Evaluated on the benchmark AI4Bharat Naamapadam dataset.
    • Training Sentences: 500 (500-shot target fine-tuning setting)
    • Validation Sentences: 150 (Held-out validation set)
    • Testing Sentences: 847 (Held-out evaluation test set)
    • Performance: 0.7668 ± 0.0094 F1 | 92.90% Accuracy (98.36% F1 recovery of 277M full fine-tuning ceiling).
  • Target Language 2 (Kokborok - Hugging Face Augmented): To overcome the extreme low-resource bottleneck, Kokborok data was ingested from Hugging Face Hub (agnivamaiti/kokborok-qa and sdmy/kokborok) and combined with curated news PDF aligned sentences.
    • Training Sentences: 4,859 (Hugging Face Augmented Corpus + News PDF Corpus)
    • Validation Sentences: 500 (Hugging Face Validation split)
    • Testing Sentences: 200 (Held-out evaluation test set)
    • Performance: 0.7482 F1 | 0.7684 Recall | 95.42% Token Accuracy (+5.05% F1 gain over 273-sentence baseline).
  • Source Datasets for Cross-Lingual Supervision: 600 sentences total (English CoNLL-2003: 150 + Hindi Naamapadam: 150 + Tamil Naamapadam: 150 + Malayalam Naamapadam: 150).
  • Entity Taxonomy: Standard BIO format with entity tags B-PER, I-PER, B-LOC, I-LOC, B-ORG, I-ORG, and O (Outside).

3. Model Backbone Architecture (Section 3)

The underlying multilingual encoder is XLM-RoBERTa-Base (xlm-roberta-base), consisting of 12 Transformer encoder layers, 768 hidden dimensions, 12 attention heads, and a vocabulary of 250,000 subwords across 100 languages. Total backbone parameter count is 277,453,063 parameters.

4. Parameter-Efficient Fine-Tuning (PEFT) Configuration (Section 4)

Instead of full fine-tuning (which updates all 277M parameters and is prone to catastrophic forgetting and overfitting), we implement Low-Rank Adaptation (LoRA r=8) using the HuggingFace peft library.

  • Backbone Status: All 277M encoder weights remain strictly FROZEN during training.
  • Target Modules: Low-rank matrices ($r=8, \alpha=16$) injected into attention projection layers ["query", "key", "value"] and intermediate feed-forward output projections ["dense"] across all 12 transformer layers.
  • Trainable Parameters: Only 1,332,487 parameters (0.4780% of total model size), updating $<0.5\%$ of model weights while recovering 98.36% of full fine-tuning F1.

5. Training & Optimization Protocol (Section 5)

Training proceeds in a two-stage cross-lingual transfer framework:

  1. Source Pre-Training: Multilingual source transfer across English, Hindi, Tamil, and Malayalam data using AdamW optimizer ($\text{lr} = 1\times 10^{-3}$) with a 10% linear warmup and linear decay schedule.
  2. Target Few-Shot & Augmented Adaptation: Target adaptation on 500 labeled Telugu sentences (`te_train.json`) and 4,859 Hugging Face Kokborok sentences (`kokborok_hf_augmented.json`), 15 epochs, batch size 32.

6. Hybrid Rule Engine & Disambiguation Rules (Section 6)

To ensure robust boundary detection and entity classification, a hybrid disambiguation engine addresses complex linguistic patterns:

  • Multi-Token Organization Disambiguation: Identifies institutional suffixes (e.g. University-ni, College-o, School-ni, Board, Association) following regional names (e.g. Tripura) to properly classify Tripura as B-ORG and University-ni as I-ORG.
  • Single-Word Person Extraction: Recognizes single-word first names (e.g. Subham) as B-PER without erroneously forcing following words into I-PER unless they match valid surnames.
  • Locative Suffix Stripping: Normalizes agglutinative Kokborok locative suffixes (e.g. Agartala-o $\to$ Agartala) to ensure consistent B-LOC tagging.

7. Evaluation Protocol & Methodological Rigor (Section 7)

Evaluations measure span-level micro-averaged Precision, Recall, seqeval F1 Score, and token-level Accuracy across random seeds (13, 42, 2024). Statistical significance is verified using paired bootstrap resampling ($10,000$ iterations, $p = 0.0001$).
