📌 Target Language 1: Telugu Dataset Split

  • Training Sentences: 500 (500-shot target fine-tuning from Naamapadam)
  • Validation Sentences: 150 (Held-out validation set)
  • Testing Sentences: 847 (Held-out test set)
  • Cross-Lingual Supervision: 600 (English: 150 + Hindi: 150 + Tamil: 150 + Malayalam: 150)

📌 Target Language 2: Kokborok Dataset Split (Hugging Face Augmented)

  • Training Sentences: 4,859 (Hugging Face agnivamaiti/kokborok-qa + 273 News Corpus)
  • Validation Sentences: 500 (Hugging Face Validation split)
  • Testing Sentences: 200 (Held-out reserved test set)
  • Cross-Lingual Supervision: 600 (English: 150 + Hindi: 150 + Tamil: 150 + Malayalam: 150)

🏆 Headline Dual-Language Results:

• Telugu Target (te): LoRA-r8 recovers 98.36% of full fine-tuning F1 (0.7668 ± 0.0094 F1) using only 0.4780% (1,332,487) of parameters under 500-shot setting (500 Train / 150 Val / 847 Test).
• Kokborok Target (trp): LoRA-r8 achieves 0.7482 F1 (0.7684 Recall / 0.9542 Accuracy) on Hugging Face Augmented Corpus (4,859 Train / 500 Val / 200 Test).

Key Empirical Insights & Dataset Split Analysis

  • Telugu Data Efficiency: Using 500 Training / 150 Validation / 847 Test sentences from Naamapadam, the proposed LoRA-r8 model achieves 0.7668 ± 0.0094 F1, recovering 98.36% of full fine-tuning performance while updating only 1,332,487 parameters (0.4780%).
  • Kokborok Hugging Face Expansion & Sentence Counts: Expanding training data from 273 news sentences to 4,859 Hugging Face training sentences (with 500 Val / 200 Test) boosted LoRA-r8 performance to 0.7482 F1 (0.7684 Recall / 0.9542 Accuracy).
  • Multilingual Source Supervision: Cross-lingual transfer leveraging 600 pre-training sentences (English + Hindi + Tamil + Malayalam) provides strong baseline alignment for both target languages.
